📇 카드북 저장 버튼 만들기

직접 만든 비즈홈에 이 버튼을 넣으면, 방문자가 버튼 한 번으로 내 명함을 자기 카드북에 저장해요.

1명함 정보 입력

이름을 입력해 주세요
https:// 로 시작하는 주소를 넣어 주세요

2버튼 모양

3코드 복사 → 비즈홈에 붙여넣기

직접 눌러보기

코드를 못 넣는 곳(링크 칸만 있는 빌더, 카톡 프로필, QR)에는 아래 저장 링크만 넣어도 돼요.

알아두세요
· 방문자가 버튼을 누르면 카드북으로 이동해 "저장할까요?" 창이 떠요. 처음 쓰는 사람만 로그인을 한 번 해요.
· 전화번호를 바꾸면 이 페이지에서 코드를 새로 만들어 다시 붙여넣어 주세요.
· 직접 만든 비즈홈은 카드북 "내 명함 통계"(열람·저장 수)에 잡히지 않아요.
